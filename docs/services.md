# Tjenester

## Digital arbeidsplass

Microsoft 365, Google Workspace, Entra ID, brukeradministrasjon, tilgangsstyring, MFA, Conditional Access, Teams, SharePoint, OneDrive, sikker konfigurasjon av PC og mobil, onboarding og offboarding, dokumentasjon, rådgivning, opplæring og fjernsupport.

## Nettsider

Bedriftsnettsider, redesign, landingssider, SEO, struktur og UX, teknisk oppsett, innhold, vedlikehold og løpende endringer. Plattformer kan blant annet være Squarespace, Shopify, Framer, Wix og Webflow.

## Digital rådgivning

Én kontaktperson for bedriftens digitale behov. Tjenestene settes sammen etter faktisk behov.

Kundeverdi først. Ikke list opp teknologier i kundekommunikasjon med mindre de er relevante.
